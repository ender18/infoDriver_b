# PROMPT: Módulo Estadísticas de Reservas — Vue 3 + Vuetify 3

## Contexto

Backend en FastAPI (`http://localhost:8000/api`).
Frontend: Vue 3 + Vuetify 3, Pinia, Axios.
Todos los endpoints requieren `Authorization: Bearer <token>`.
Permiso requerido: `stats:read`.

El módulo consulta la base de datos de Autocab para obtener un resumen de reservas completadas y canceladas en un rango de fechas, con desglose por día. No llama a API externa — la respuesta es inmediata.

---

## Endpoint

```
GET /stats/bookings/summary?date_from=YYYY-MM-DD&date_to=YYYY-MM-DD
Authorization: Bearer <token>
```

### Respuesta exitosa — 200

```json
{
  "date_from": "2026-03-01",
  "date_to":   "2026-03-02",
  "summary": {
    "completed":       142,
    "cancelled":        38,
    "total":           180,
    "unique_vehicles":   5
  },
  "by_day": [
    { "date": "2026-03-01", "completed": 80, "cancelled": 20, "total": 100, "unique_vehicles": 4 },
    { "date": "2026-03-02", "completed": 62, "cancelled": 18, "total":  80, "unique_vehicles": 3 }
  ]
}
```

### Errores posibles

| Código | Detalle                                         |
|--------|-------------------------------------------------|
| 401    | Token inválido o ausente                        |
| 403    | Permission required: stats:read                 |
| 422    | date_to anterior a date_from / params faltantes |
| 502    | Error consultando la base de datos de Autocab   |

## Tarea frontend

### 1. Módulo API — `src/api/stats.js` (nuevo archivo)

```js
import api from './axios'

export const getBookingsSummary = (dateFrom, dateTo) =>
  api.get('/stats/bookings/summary', {
    params: { date_from: dateFrom, date_to: dateTo }
  })
```

### 2. Store Pinia — `src/stores/statsStore.js` (nuevo)

```js
import { defineStore } from 'pinia'
import { getBookingsSummary } from '@/api/stats'

export const useStatsStore = defineStore('stats', {
  state: () => ({
    isLoading: false,
    result:    null,   // { date_from, date_to, summary, by_day[] }
    error:     null,
  }),
  actions: {
    async fetchBookingsSummary(dateFrom, dateTo) {
      this.isLoading = true
      this.error     = null
      this.result    = null
      try {
        const { data } = await getBookingsSummary(dateFrom, dateTo)
        this.result = data
      } catch (err) {
        this.error = { code: err.response?.status, detail: err.response?.data?.detail }
      } finally {
        this.isLoading = false
      }
    },
    clear() {
      this.isLoading = false
      this.result    = null
      this.error     = null
    },
  },
})
```

#### Botón "Exportar CSV"

Exporta el desglose `by_day` más una fila final de totales:

```js
const exportCSV = () => {
  const cols = ['date', 'completed', 'cancelled', 'total', 'unique_vehicles']
  const rows = stats.result.by_day.map(r =>
    cols.map(c => `"${r[c] ?? ''}"`).join(',')
  )
  const totals = cols.map(c =>
    c === 'date' ? '"TOTAL"' : `"${stats.result.summary[c] ?? ''}"`
  ).join(',')
  const csv  = [cols.join(','), ...rows, totals].join('\n')
  const blob = new Blob([csv], { type: 'text/csv' })
  const url  = URL.createObjectURL(blob)
  const a    = document.createElement('a')
  a.href     = url
  a.download = `stats_${stats.result.date_from}_${stats.result.date_to}.csv`
  a.click()
  URL.revokeObjectURL(url)
}
```

## Notas

- `summary` son los totales del período completo; `by_day` es el desglose diario.
- Si `by_day` tiene un solo elemento (rango de un día), omitir la tabla y mostrar solo las tarjetas KPI.
- El rango de fechas es inclusivo: 00:00:00 → 23:59:59 (el backend lo maneja, el frontend solo envía `YYYY-MM-DD`).
- La respuesta no incluye días sin reservas — si un día no aparece en `by_day` es porque no hubo ninguna.
- Las tarjetas KPI deben poder crecer: si en el futuro se agrega un campo nuevo a `summary`, solo hay que agregar una tarjeta más sin reestructurar el layout.
