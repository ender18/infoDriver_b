──────────────────────────────────────
GET /payments/transactions/{id}
──────────────────────────────────────
Detalle completo de una transacción específica, incluyendo todos sus
webhook events recibidos (en orden cronológico).

Misma estructura que un objeto del array "results" de arriba.

──────────────────────────────────────
GET /payments/transactions/{id}/log
──────────────────────────────────────
Log de eventos de auditoría de una transacción (útil para debugging).
Muestra el historial completo de eventos internos con su payload.

Respuesta:
[
  {
    "id": 1,
    "event_type": "payment_initiated",
    "driver_id": 42,
    "session_id": "uuid-...",
    "history_id": 15,
    "payload": { ... },
    "created_at": "2026-05-30T17:55:00Z"
  },
  {
    "id": 2,
    "event_type": "webhook_received",
    ...
  }
]

Tipos de event_type posibles:
  - payment_initiated   → se envió la transferencia a PEIBO
  - payment_error       → falló el envío
  - webhook_received    → PEIBO confirmó el resultado
  - webhook_error       → llegó un webhook sin transacción asociada

─────────────────────────────────────────────────────────────────────────────
4. CAMPOS DE STATUS
─────────────────────────────────────────────────────────────────────────────

peibo_transactions.status:
  - pending    → transferencia enviada, esperando confirmación de PEIBO
  - success    → PEIBO confirmó liquidación ("Liquidada")
  - failed     → PEIBO rechazó la transferencia ("Rechazada")
  - refunded   → PEIBO devolvió el dinero ("Devuelta")
